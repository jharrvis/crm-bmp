# Sumber Data Wilayah

Data CSV pada folder ini berasal dari proyek [idn-area-data](https://github.com/fityannugroho/idn-area-data), dipin pada commit `b36d0792e039555eee86bda3d3092cdfcacb16f4` (2026-02-20) dan diunduh pada 2026-08-06.

- Data administratif disediakan di bawah Open Database License (ODbL); teks lisensi disertakan di `LICENSE.md`.
- Kode proyek upstream menggunakan lisensi MIT.
- Data hanya dipakai sebagai referensi dropdown lokal dan tidak diakses dari API publik saat aplikasi berjalan.

Saat memperbarui data, gunakan versi upstream yang tervalidasi, pertahankan struktur CSV, dan jalankan kembali `AdministrativeAreaSeeder`.
